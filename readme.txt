# Admin and User Panel Project

## Overview
This project is a web application that provides an admin panel and a user panel with various functionalities. The admin panel allows for managing user accounts, while the user panel provides functionalities like uploading photos and resetting passwords.

## Technologies are
- Node.js
- Express.js
- MySQL
- bcrypt for password hashing
- JWT for authentication
- Multer for file uploads

## Prerequisites
- Node.js
- MySQL
